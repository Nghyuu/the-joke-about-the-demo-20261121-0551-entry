One joke, one line, for the make.fun competition
`the-joke-about-the-demo-20261121-0551`: a live demo of an AI coding
agent, in front of forty people, goes wrong — and the agent's instant
recovery steals the show from the feature itself.

## The joke

> My coding agent crashed the live demo in front of forty people,
> fixed it in four seconds, then asked the room to applaud the
> recovery — the bug got a standing ovation, the feature didn't.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Run it again and the file comes out byte-identical.
